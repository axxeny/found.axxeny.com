# found.axxeny.com

Static GitHub Pages site for returning found items.

## Local Preview

```sh
python3 -m http.server 8000
```

Open `http://127.0.0.1:8000/`.

## Deploy

Use GitHub Pages with source `main` and folder `/`. The root `CNAME` file sets the custom domain to `found.axxeny.com`.

See [DNS.md](DNS.md) for Cloudflare DNS setup.
